## Introduction

This repository contains practical examples of using variables in CSS and SCSS, based on learning materials originating from Harvard University. It demonstrates how variables can be used to define and reuse styling values in HTML web pages.

## Topics Covered

- Introduction to CSS variables
- Defining and using SCSS variables
- Storing reusable values in variables
- Applying variables to HTML elements
- Styling unordered and ordered lists
- Using variables to manage text colors
- Connecting HTML files with external CSS stylesheets

## Learning Approach

The examples demonstrate how to define a variable in SCSS, reuse its value across CSS rules, and apply styling to HTML list elements.
